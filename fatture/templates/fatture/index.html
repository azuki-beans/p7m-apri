Come funziona

La fattura elettronica è un file .xml che segue il tracciato FatturaPA dell'Agenzia delle Entrate: leggibile dai gestionali, ma poco pratico da consultare a occhio. Questo strumento lo impagina in un PDF ordinato con dati del cedente e del cliente, righe di dettaglio, riepilogo IVA, totali e modalità di pagamento.

Trascina o seleziona il file qui sopra e premi Genera anteprima PDF: vedrai subito la fattura impaginata e potrai scaricarla. Se la fattura ti è arrivata come .p7m (XML firmato), puoi caricarlo così com'è: l'XML viene estratto automaticamente.

Usarlo come API

Lo stesso servizio è disponibile via HTTP: invia una fattura .xml o .p7m in POST e ricevi il PDF.

# file multipart
curl -F file=@fattura.xml {{ api_url }} -o fattura.pdf

# oppure byte grezzi nel corpo, con colore tema personalizzato
curl --data-binary @fattura.xml.p7m \
     "{{ api_url }}?accent=%231D4ED8" -o fattura.pdf

Parametri query opzionali: accent (colore HEX del tema, es. %231D4ED8), dl=1 per forzare il download, filename per il corpo grezzo. In caso di errore la risposta è JSON {"error": …}.

Domande frequenti

I miei file vengono conservati?

No. La fattura viene elaborata in memoria e il PDF risultante è tenuto solo per il download, poi cancellato automaticamente dopo un'ora.

Il PDF ha valore fiscale?

No: è una rappresentazione grafica di cortesia. Il documento con valore legale resta l'XML firmato originale.
